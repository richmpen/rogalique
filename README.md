## 📝 Описание

Rogalique - это учебный проект игры в жанре рогалик, разработанный в рамках финальной работы по курсу C++ и для практики использования системы контроля версий Git. Игра представляет собой процедурно генерируемые уровни с элементами боевой системы, где игрок должен преодолевать препятствия и сражаться с врагами.

## 🎮 Особенности

- Процедурная генерация лабиринтов
- Система боя с врагами
- Физическая система с коллизиями
- Компонентно-ориентированная архитектура

## 🏗️ Структура проекта

Проект разделен на несколько основных модулей:

- **Engine** - Собственный игровой движок с компонентной архитектурой
  - Система рендеринга
  - Физическая система
  - Система управления ресурсами
  - Система логирования
  - Компонентная система для игровых объектов
  - и другие.

- **Rogalique** - Основная игровая логика
  - Генерация лабиринтов
  - Игровые состояния
  - Игровые объекты (игрок, враги, стены, пол, музыка)

## 🛠️ Технологии

- C++
- SFML (Simple and Fast Multimedia Library)
- Собственный игровой движок с компонентной архитектурой

## 🚀 Установка и запуск

### Требования

- Visual Studio 2019 или новее
- SFML 2.5.1 или новее

### Сборка проекта

1. Клонировать репозиторий:
```
git clone https://github.com/richmpen/rogalique
```

2. Открыть решение `Game.sln` в Visual Studio

3. Собрать проект (Build -> Build Solution)

4. Запустить игру (Debug -> Start Debugging или F5)

## 🎯 Управление

- WASD - перемещение игрока
- Esc - пауза/выход в меню


## 🧠 Архитектура

Проект использует компонентно-ориентированную архитектуру, где:

- Игровые объекты состоят из различных компонентов
- Системы обрабатывают объекты с определенными компонентами
- Состояния игры управляют потоком игры
