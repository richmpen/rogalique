# Документация по FightComponent

## Что это такое?

**FightComponent** позволяет игровым объектам (например, игрокам или врагам) участвовать в бою. С его помощью объекты могут наносить урон другим объектам и получать урон в ответ. Если здоровье объекта падает до нуля, он умирает и исчезает из игры.

## От чего зависит?

Для работы **FightComponent** игровому объекту нужны два дополнительных компонента:

- **SpriteColliderComponent** — отвечает за обнаружение столкновений. Без него объект не сможет определить, что с кем-то столкнулся.
- **SpriteRendererComponent** — используется для визуальных эффектов, например, чтобы объект покраснел при получении урона.

Если **SpriteColliderComponent** отсутствует, **FightComponent** не будет функционировать и автоматически удалится.

## Что умеет?

**FightComponent** предоставляет следующие возможности:

- **Нанести урон.** При столкновении с другим объектом, у которого также есть **FightComponent**, и если они относятся к разным "командам" (targetType), объект наносит урон. После этого наступает пауза в 1 секунду, чтобы атаки не были слишком частыми.
- **Получить урон.** Когда объект получает урон, его здоровье уменьшается. Если здоровье достигает 0, объект умирает.
- **Взрыв крипера.** Если объект — крипер и он столкнулся с игроком, начинается обратный отсчёт в 2 секунды, после чего крипер взрывается и исчезает.
- **Смерть.** При исчерпании здоровья объект удаляется из игры.

## Какие есть параметры?

**FightComponent** имеет три основных параметра для настройки:

- **damage** — количество урона, которое объект может нанести за один раз.
- **health** — количество здоровья (жизней) у объекта.
- **targetType** — "команда" объекта, например, "Player" (игрок) или "Enemy" (враг). Объекты из одной команды не атакуют друг друга.

## Как управлять?

**FightComponent** включает методы для изменения параметров и выполнения действий:

- **SetDamage(int damage)** — задаёт количество урона, которое объект будет наносить.
- **GetDamage()** — возвращает текущее значение урона.
- **SetHealth(int health)** — задаёт количество здоровья.
- **GetHealth()** — возвращает текущее здоровье.
- **SetTargetType(TargetType type)** — задаёт "команду" объекта (например, Player или Enemy).
- **GetTargetType()** — возвращает текущую "команду" объекта.
- **TakeDamage(int amount)** — наносит объекту урон на указанное количество.
- **Die()** — немедленно "убивает" объект и удаляет его из игры.

## Как это работает в игре?

1. При столкновении двух объектов (например, игрока и врага) **FightComponent** проверяет:
   - Есть ли у второго объекта **FightComponent**.
   - Принадлежат ли они к разным "командам" (targetType).
   - Не исчерпано ли здоровье и не находится ли атака на перезарядке.
2. Если условия выполнены, первый объект наносит урон второму. Визуально это может проявляться так: объект, получивший урон, краснеет на 2 секунды.
3. Если объект — крипер и он столкнулся с игроком, он переходит в режим взрыва: меняет текстуру (например, на "creeperExplosion"), перестаёт двигаться и через 2 секунды исчезает.

## Пример использования

Чтобы создать игрока и врага:

1. Создайте игровой объект для игрока и добавьте ему **SpriteColliderComponent**, **SpriteRendererComponent** и **FightComponent**.
2. Настройте параметры: для игрока — 100 здоровья, 10 урона, "команда" — Player.
3. Создайте аналогичный объект для врага: 50 здоровья, 5 урона, "команда" — Enemy.
4. При столкновении игрок нанесёт врагу 10 урона, а враг игроку — 5. Если здоровье у кого-то из них достигнет 0, он умрёт.

## Дополнительные особенности

- **Перезарядка атаки:** после нанесения удара объект ждёт 1 секунду, прежде чем сможет атаковать снова.
- **Крипер:** при столкновении с игроком крипер перестаёт двигаться, через 2 секунды взрывается и удаляется.
- **Цвет при уроне:** при получении урона объект краснеет на 2 секунды, затем возвращается к обычному цвету.
